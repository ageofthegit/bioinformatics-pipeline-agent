# Bioinformatics Agent Roadmap

```text
Bioinformatics Agent Roadmap
│
├── Phase 1: Basic agent
│   └── Read data → make plan → ask permission → create report
│
├── Phase 2: Better data checks
│   └── Measure DNA-read quality and flag possible problems
│
├── Phase 3: Nextflow
│   └── Run the analysis as a repeatable scientific pipeline
│
├── Phase 4: Monitoring and recovery
│   └── Track jobs → explain failures → ask before one retry
│
├── Phase 5: MCP
│   └── Let other AI applications use the agent's tools safely
│
├── Phase 6: LLM explanations
│   └── Explain plans and results in simpler language
│
├── Phase 7: Evaluation
│   └── Test whether the agent is accurate and reliable
│
├── Phase 8: Public dataset
│   └── Demonstrate the agent on approved real-world data
│
├── Phase 9: Compute queue
│   └── Simulate running larger jobs on shared computers
│
├── Phase 10: Provenance
│   └── Record exactly which data, code and settings were used
│
├── Phase 11: User pilot
│   └── Let a real user try it and collect feedback
│
└── Phase 12: Application evidence
    └── Prepare the repository, demo and project explanation
```

Current position: Phase 11 project-owner review is in progress. Phase 12's local visual dashboard is built; repository publication follows the remaining reviews.
